# Stage 关键词胶囊对齐修复设计

## 目标

修复 Stage 版「大家眼中的周老师」页面中关键词胶囊文字未处于正中、字号大小不一致的问题，同时保持现有页面结构、配色、内容和播放逻辑不变。

## 修改范围

- 仅调整 `stage.css` 中 `.keyword-wall span` 相关样式。
- 所有关键词使用同一套字号、字重和行高。
- 胶囊改为 `inline-flex`，并通过水平、垂直居中规则保证文字位于胶囊中央。
- 移除特定序号关键词的字号放大和垂直位移；其颜色、边框与背景变化继续保留。
- 更新 `stage.html` 中 Stage 样式表的缓存版本，确保浏览器加载修复后的 CSS。
- 不修改手机端 `style.css`，不修改关键词内容或 Stage 播放逻辑。

## 验收标准

- 「大家眼中的周老师」页面内全部关键词字体大小一致。
- 每个关键词在其胶囊内水平、垂直居中。
- 胶囊之间仍可保留现有颜色层次，但不再出现上下错位。
- Stage 页面能够正常加载、自动播放和手动切换。
- `git diff --check` 通过，且浏览器控制台无新增错误。
