# Stage 大屏字号调整设计

## 目标

提升现场大屏放映的远距离可读性，同时保持现有 Stage 自动播放、画面结构和内容不变。

## 调整范围

- 仅修改 `stage.css`。
- 页眉状态、开场正文、照片说明、关键词、祝福、故事、视频说明、成果列表、结束页说明和控制提示放大约 12%–16%。
- 已经足够醒目的章节主标题、开场主标题和巨型装饰数字不继续放大，避免溢出或破坏画面层级。
- 祝福视频中的姓名标题改用与“周洁红教授 · 治学长卷”一致的宋体字体栈，现有字号、字重和字距不变。
- 暖心小故事正文在首轮字号调整基础上再放大约 12%–13%，标题、署名、行距和自动滚动逻辑保持不变。
- 不修改手机端样式、Stage 数据、自动播放逻辑、脚本版本或服务器文件。

## 验收

- 在 1920×1080 视口检查开场、照片、祝福、故事、视频、成果和结束场景。
- 正文与辅助文字明显增大，无横向溢出、遮挡或内容裁切。
- 祝福视频姓名标题使用宋体，与治学长卷标题保持一致，字号不变。
- 暖心小故事正文在大屏上更易阅读，且仍可通过既有自动滚动完整展示。
- 本地 Stage 可正常自动播放与手动切换。
