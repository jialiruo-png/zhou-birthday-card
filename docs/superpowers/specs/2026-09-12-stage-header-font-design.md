# Stage 顶部章节标题字体调整设计

## 目标

将 Stage 顶部章节名称（如「先看见周老师」「人物序章」「文字心意」「师生故事」）以及全部照片主标题（如「卡特年末工作会议留影」「调研交流中的专注笃定」）的字体改为「周洁红教授 · 治学长卷」标题使用的宋体字体栈。

## 范围

- 仅修改 `.stage-header h2` 和 `.photo-scene__copy h3` 的 `font-family`。
- 保持原有字号、字重、字距、间距、颜色和位置不变。
- 不修改其他场景主标题、开场标题、结束页或手机端。

## 验收

- Stage 顶部全部章节名称使用宋体字体栈。
- Stage 全部照片主标题使用宋体字体栈。
- 上述文字的尺寸和布局与修改前一致。
