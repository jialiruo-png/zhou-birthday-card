# Stage 滚动场景 1.5 倍速设计

## 目标

将 Stage 版「师生故事」和「治学长卷」两个自动滚动场景的整段播放速度提高到当前的 1.5 倍，滚动完成后随即按同比缩短的时间自动切换到下一场景。

## 实现

- 在 `stage.js` 中增加仅作用于上述两个场景的 1.5 倍速系数。
- 师生故事的动态总时长在现有计算结果上除以 1.5，不改变不同故事按文字长度分配时长的规则。
- 治学长卷的总时长从 120 秒同比缩短为 80 秒。
- 两类场景的开头停顿、自动滚动和末尾停顿均按同一系数同比缩短，保持现有滚动曲线和画面节奏比例。
- 不调整祝福、照片、视频、章节页、结束页或手机端的播放速度。
- 更新 Stage 脚本缓存版本，确保浏览器加载新逻辑。

## 验收标准

- 师生故事从进入到自动切页的总耗时为修改前的三分之二。
- 治学长卷约 80 秒播放完毕并自动进入结束页。
- 两类场景都能滚动到底，不在滚动结束后长时间空等。
- 暂停、继续、上一页、下一页和重新播放保持正常。
- `node --check stage.js` 与 `git diff --check` 通过，浏览器控制台无新增错误。
