# 宴会大屏版使用说明

## 入口

- 手机纪念册：`index.html`
- 宴会大屏版：`stage.html`

大屏版是独立的 `16:9` 横屏自动放映页面，不会改变手机版效果。

## 推荐现场环境

- 电脑：Windows 或 macOS 笔记本
- 浏览器：最新版 Chrome 或 Edge
- 输出：HDMI 连接投影仪或 LED 屏
- 分辨率：优先 `1920×1080`，同时兼容 `1366×768`、`2560×1440` 和 4K
- 系统缩放：建议保持 `100%`
- 放映前请关闭系统通知、微信弹窗和自动休眠

## 启动方式

### 在线播放

部署到 GitHub Pages 后访问：

`https://你的用户名.github.io/仓库名/stage.html`

页面打开后会停留在暖场封面。主持人准备好后点击“开始放映”，浏览器会尝试进入全屏并开始背景音乐，之后自动播放全程。

### 本地播放

在项目目录运行静态服务器：

```bash
python3 -m http.server 8000
```

然后用 Chrome 或 Edge 打开：

`http://localhost:8000/stage.html`

Windows 也可以双击 `start-stage.bat`；macOS 可在终端执行 `bash start-stage.sh`。

> 不建议直接双击 `stage.html`，部分浏览器会限制本地视频读取。

## 自动播放流程

1. 暖场封面：等待主持人点击开始
2. 开场祝词
3. 人物序章与三章照片：自动切换
4. 文字心意：关键词、精选祝福、师生故事
5. 五段祝福视频：逐段自动播放，结束后自动切换下一段
6. 治学长卷：自动向下滚动，顶部和底部均预留停留时间
7. 尾声与筹备组名单

全程约 **11 分钟**。背景音乐默认循环播放；进入视频时自动暂停，视频结束后自动恢复。

## 现场快捷键

| 操作 | 快捷键 |
|---|---|
| 暂停／继续 | `空格` |
| 上一幕 | `←` |
| 下一幕 | `→` |
| 静音／恢复声音 | `M` |
| 进入／退出全屏 | `F` |
| 从头重播 | `R` |

鼠标移动时，底部会出现控制条，也可以点击控制。

## 现场彩排建议

1. 至少提前完整播放一遍，确认五段视频和音乐都有声音。
2. 将电脑接入正式投影仪后再次测试画面比例与音量。
3. 建议关闭浏览器其他标签页和占用网络的软件。
4. 若使用在线 GitHub Pages，建议提前完整播放一次，让浏览器缓存视频。
5. 最稳妥的方式是在电脑本地启动静态服务器播放，避免宴会厅网络波动。
